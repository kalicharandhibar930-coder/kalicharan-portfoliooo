# Kalicharan Dhibar — Portfolio Website

## Files
- `index.html` — all website sections and embedded mini-apps
- `style.css` — dark, neon-green responsive design
- `script.js` — mobile menu, to-do list, product search/filter/sort
- `assets/hero-video.mp4` — the supplied hero background video

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted `kalicharan-portfolio` folder in VS Code.
3. Keep `assets/hero-video.mp4` at the same path; the video is referenced by `index.html`.
4. Install the **Live Server** extension if needed.
5. Right-click `index.html` → **Open with Live Server**.

## Profile photo
Your uploaded profile image is already saved as `assets/profile.jpg` and displayed in the hero section.

## Notes
- The products and prices are sample/demo data.
- Keep the skill list accurate to your current ability.
- The to-do app stores tasks in the browser's localStorage.
- This is a single-page website; all three main project areas are included on the same page.
